# polylane_workspace_autofix_settings (Resource)

Manages workspace-wide autofix behavior. This is an existing workspace singleton: create and update use PATCH, while destroy only stops Terraform management and does not reset the remote settings.

## Example Usage

```terraform
resource "polylane_workspace_autofix_settings" "current" {
  workspace_id = "ws_00000000000000000000000000000000"
  enabled      = true
  trigger_mode = "approval"
}
```

## Schema

### Required

- `enabled` (Boolean) Whether Polylane may open new autofix pull requests for repositories in this workspace.
- `trigger_mode` (String) How machine-initiated autofixes start. `auto` starts immediately; `approval` waits for approval in the console.
- `workspace_id` (String) ID of the workspace whose settings are managed.

### Optional

- `review_bot_login` (String) GitHub login whose review is requested on each autofix pull request. Omit to request no bot review.
